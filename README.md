# Mini S3 - AWS S3 핵심 기술 구현 (C)

AWS S3가 하드디스크로 초당 1PB를 처리하는 핵심 기술 3가지를 C로 구현한 시뮬레이터.

## 구현된 기술

### 1. 데이터 분산 저장 (Data Striping)
데이터를 잘게 쪼개서 여러 디스크에 분산 저장 → 병렬 읽기/쓰기로 속도 N배 향상.

### 2. Power of Two Choices
디스크를 랜덤 2개 골라서 사용률이 낮은 쪽에 저장. 단순하지만 분포가 극적으로 균등해진다.

### 3. 이레이저 코딩 (Erasure Coding)
Reed-Solomon 코드(Cauchy 행렬 + GF(256))로 패리티 조각을 생성.
5개 데이터 + 4개 패리티 = 9개 조각 중 아무 5개만 있으면 원본 복구 가능.
단순 복제(2배) 대비 1.8배만 용량이 늘어나면서 더 높은 내결함성 제공.

## 빌드 & 실행

```bash
make        # 빌드
make run    # 데모 실행
make test   # 종합 실험 실행
make clean  # 정리
```

## 파일 구조

```
gf256.h / gf256.c      - GF(256) 갈루아 필드 연산 (이레이저 코딩의 수학적 기반)
erasure.h / erasure.c   - Reed-Solomon 이레이저 코딩 (Cauchy 행렬 기반 MDS 코드)
main.c                  - 3가지 기술 데모
test.c                  - 종합 실험 및 벤치마크 (7개 항목)
Makefile                - 빌드 설정
```

### [4] Power of Two Choices 통계 분석

디스크당 평균 100개 데이터, 200회 시행.

| 디스크 | 방식 | 평균 최대 | 평균 최소 | 표준편차 | 최대/평균 |
|--------|------|----------|----------|---------|----------|
| 16 | rand | 118.2 | 82.7 | 9.5 | 1.1816 |
| 16 | **P2C** | **101.2** | **98.2** | **0.9** | **1.0122** |
| 64 | rand | 124.2 | 77.2 | 9.9 | 1.2419 |
| 64 | **P2C** | **101.8** | **97.3** | **0.9** | **1.0175** |
| 256 | rand | 129.8 | 73.0 | 10.0 | 1.2983 |
| 256 | **P2C** | **102.0** | **96.3** | **1.0** | **1.0202** |
| 512 | rand | 131.9 | 71.0 | 10.0 | 1.3185 |
| 512 | **P2C** | **102.0** | **96.0** | **1.0** | **1.0203** |

핵심: 디스크가 512개로 늘어나면 랜덤 배치의 최대 부하는 32%까지 치솟지만, P2C는 2%로 유지. 표준편차는 **10배 이상** 감소.

### [6] 읽기 꼬리 지연시간

정상 디스크 1-5ms, 지연 디스크(5% 확률) 50-200ms 시뮬레이션. 100,000회 시행.

| 백분위 | 기본 (5개 대기) | 헤지 (9개 중 5개) | 개선율 |
|--------|---------------|------------------|--------|
| P50 | 5.0 ms | 3.0 ms | 40.0% |
| P90 | 137.0 ms | 4.0 ms | **97.1%** |
| P95 | 169.0 ms | 4.0 ms | **97.6%** |
| P99 | 195.0 ms | 5.0 ms | **97.4%** |
| P99.9 | 200.0 ms | 5.0 ms | **97.5%** |

핵심: 이레이저 코딩을 활용한 헤지 읽기로 P99 지연시간이 **195ms → 5ms** (97% 감소). 느린 디스크를 기다리지 않고 다른 조각으로 우회.

### [7] 저장 방식 효율 비교

| 방식 | 저장 배율 | 내결함성 (디스크) | 최소 디스크 |
|------|----------|-----------------|------------|
| 복제 없음 | 1.0x | 0 | 1 |
| 2중 복제 | 2.0x | 1 | 2 |
| 3중 복제 | 3.0x | 2 | 3 |
| **RS(5,4) - S3 방식** | **1.8x** | **4** | **9** |

RS(5,4): 3중 복제 대비 **40% 적은 용량**으로 **2배 높은 내결함성**.
